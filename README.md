## Summary
This course covered advanced algorithm theory, code efficiency, and testing. 

## Final Project
The capstone project for this course implemented a Huffman Compression algorithm without the use of built in functions or libraries when possible. Program scans a dataset for character frequencies, builds a Huffman Tree from these frequencies, and creates a code dictionary. The file is then encoded into binary with a dictionary based header, and the decode function is run to confirm the accuracy of the program. Included is datasets, a testing plan, and a "invalid.csv" file used for testing.
